☁️ 云端存储

开启后，作业存在云数据库里，手机和电脑不管在哪、用什么网络，看到的都是同一份。

✅ 云端配置已内置，打开就能用，一般不用改。换设备时只要填同一个「家庭码」即可。

未开启同步
Supabase 怎么配？（约 3 分钟）
  1. 打开 supabase.com 注册并新建项目，选免费套餐即可（地区建议 Singapore 或 Tokyo，国内访问更快）
  2. 左侧 SQL Editor → New query，粘贴下面这段后点 Run
create table homework (
  code text primary key,
  items jsonb not null default '[]'::jsonb,
  updated_at timestamptz not null default now()
);

alter table homework enable row level security;

create policy "homework_all" on homework
  for all to anon using (true) with check (true);
  1. 左侧 Project Settings → API，把 Project URL 和 anon public 复制回来填到上面
  2. 手机和电脑都填同一个家庭码，点「测试连接」，出现绿色的「已连接云端」就成功了

提示：家庭码相当于数据钥匙，建议用 姓名+班级+随机数字 这种不容易猜到的组合。

自建服务怎么配？

在服务器或家里的电脑上运行 server.js（macOS 双击 启动.command，Windows 双击 启动.bat），把显示的地址填到上面的「云端地址」。

用 http://192.168.x.x:3000 这类局域网地址时，手机要连同一个 Wi-Fi；部署成公网域名后，在外面也能用。
